OpenProxy

Desktop Application · Electron + Vue 3 · Open Source

OpenProxy is a fast, modern network debugging proxy built for developers. It combines the raw power of mitmproxy with a sleek, native-feeling desktop UI. Perfect for inspecting HTTP/HTTPS traffic, mocking API responses, rewriting URLs, and testing network conditions.

Key Features
  • Traffic Interception - view, inspect, and filter HTTP/HTTPS requests in real time
  • Map Local (Mocking) - trick your app into receiving custom JSON/HTML responses
  • Map Remote (Rewrites) - transparently route URLs to localhost dev servers
  • Live Breakpoints - pause requests mid-flight, edit headers and bodies
  • VPN Mode - route device traffic through a WireGuard tunnel
  • Smart Android Setup - 1-click ADB integration with auto-update
  • Network Throttling - simulate various network conditions
